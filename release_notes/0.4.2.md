# Release notes: 0.4.2

This release covers changes since 0.4.1.

## Highlights

- Improved patch application for repositories that have BL commit-locking hooks installed.
- BL now removes its generated pre-commit lock before repository processing and patch application, then restores the lock afterward.

## Fixes

- Patch application no longer trips over BL's own generated pre-commit lock hook.
- Managed repositories keep their commit-locking behavior after processing completes.

## Internal changes

- Added shared helpers for adding and removing BL-generated pre-commit locks.
- Added tests covering hook removal and locking behavior around repository processing.

## Migration notes

- No user action is required. Existing managed repositories continue to be locked against accidental commits after BL finishes processing them.
